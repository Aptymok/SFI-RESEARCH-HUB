# START HERE — SFI Research Hub

This repository is the governed research workspace for the System Friction Institute. It is not a claim that System Friction Theory (SFT) is validated.

## Read this repository in this order

1. `STATUS.md` — current epistemic state of every research object.
2. `00_REGISTRY/HYPOTHESIS_LEDGER.csv` — hypotheses, counter-hypotheses, falsifiers, and evidence state.
3. `GOVERNANCE.md` — rules that separate observation, inference, proposal, synthetic evidence, and falsification.
4. `01_INDIVIDUATION/` — Research Object A.
5. `02_AI_OBSERVABILITY/` — Research Object B.
6. `03_SYSTEM_FRICTION_THEORY/` — prospective SFT specification and falsification protocol.
7. `04_CHI_2027/` — anonymous review/export surface for the CHI route.
8. `REPRODUCE.md` — how to rerun available synthetic engineering checks.
9. `RELEASES_AND_ZENODO.md` — how frozen versions become citable research objects.

## Epistemic labels

- `OBSERVED` — directly recorded from an eligible empirical source.
- `DERIVED` — computed from observed data using a recorded transformation.
- `INFERRED` — interpretation supported by evidence but not directly observed.
- `SYNTHETIC` — generated benchmark/test data; never external empirical evidence.
- `PROPOSED` — hypothesis, model, construct, or mechanism not yet established.
- `FROZEN_CANDIDATE` — prospectively specified claim awaiting immutable timestamp/release.
- `FALSIFIED` — contradicted under its preregistered test conditions.
- `NOT_TESTED` — no eligible empirical test has yet been completed.

## Core scientific rule

The purpose of the Hub is not to preserve SFI claims. The purpose is to preserve the trace of how claims change when observations disagree with them.

A claim may move from `PROPOSED` to `SUPPORTED_IN_DOMAIN` only through a registered protocol, eligible evidence, reproducible analysis, and explicit comparison with alternatives. Null and negative results remain part of the record.

## What exists now

The Hub currently contains working bilingual manuscripts, protocols, synthetic engineering benchmarks, candidate external datasets, an adversarial hypothesis ledger, and SFT-0.1 as a prospective falsifiable specification. No empirical validation of SFT is claimed.
