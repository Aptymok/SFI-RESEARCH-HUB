# SFI-B — From AI Governance to AI Observability

## Scientific role

This project tests the distinction between governance structures and the ability to reconstruct state transitions in human–AI systems.

Core trace:

`state -> intervention -> transition -> outcome`

The project asks whether governance controls alone are sufficient for reconstruction, or whether explicit observability instrumentation is required.

## Independence constraint

Results may support, weaken, or contradict System Friction Theory. SFI-B must not define observability through SFT-specific constructs.

## Minimum evidence package

- operational definitions of governance completeness and observability;
- trace reconstruction protocol;
- at least one declared baseline/null condition;
- event/source provenance;
- reproducible notebook or executable analysis;
- negative and failed cases, not only successful reconstructions;
- limitations and threat-to-validity register.

## Release condition

A public v1.0 requires a reconstructable evidence chain and an explicit account of cases where observability fails.
