# SFI-A Scope Correction Report — 2026-08-20

## What happened
The program temporarily over-weighted a biological lineage benchmark while searching for independent ground truth. This caused the empirical implementation to drift from the original SFI-A object: operational individuation of sociotechnical/AI systems.

## What is preserved
Nothing is deleted. The CTC/HeLa permission request, runner, provenance design, hypotheses, and code remain as `A-TRANSFER-BIO`.

## What is restored
The primary SFI-A object is the measurement relation `H_id(A,B | Omega)` for longitudinal AI/sociotechnical systems, explicitly separating system, model, agent/runtime, artifact, evidence, memory, tools, authority, governance, data boundary, environment, and provenance.

## Why the correction is scientifically useful
The divergence itself is evidence about research-process risk: availability of a clean benchmark can pull a measurement program toward the benchmark's ontology. The correction therefore becomes part of provenance and demonstrates that domain selection must not redefine the target construct.

## Current order
1. SFI-A-AI-PRIMARY — primary operational individuation validation in AI/sociotechnical systems.
2. A-TRANSFER-BIO — external biological transfer/adversarial test.
3. Additional transfer domains only after the AI-domain measurement relation is frozen.

## Consequence for SFT
None of this validates SFT. SFI-A remains independently falsifiable. The restored scope strengthens the precondition for later SFT work: before measuring persistence, transition, or friction, the program must be able to declare what operational object is being tracked and under which boundary/time scale.

## Governance status
Recorded by ADR-004. Future state reports must include this divergence and correction until at least the first SFI-A-AI-PRIMARY empirical execution is complete.
