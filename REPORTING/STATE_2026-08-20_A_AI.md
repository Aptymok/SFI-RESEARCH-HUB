# SFI-A State Report — AI Operational Individuation

Date: 2026-08-20
Canonical branch: main

## Current phase
Prior-art bounded benchmark design / pre-adjudication.

## What changed
The biological cell-tracking path is retained as an external transfer benchmark, not the primary scientific object. The primary object is operational individuation of AI/sociotechnical systems across transformations.

## Current scientific question
Given two observations of an AI system under a declared purpose and observation boundary, can a multi-dimensional operational-individuation rule distinguish SAME / DISTINCT / UNRESOLVED better than strong dimension-specific baselines?

## Existing work absorbed rather than replicated
- STATE-Bench: memory value in agent performance.
- Mem2ActBench: active use of long-term memory for action.
- ContinuityBench variants: interrupted-state recovery and/or behavioral continuity.
- IETF agent identity/provenance proposals: authenticated identity, delegation, provenance and history.
- AI Identity gap-analysis literature: substrate, persistence, verifiability and governance gaps.

## Candidate novelty boundary
SFI-A survives only if operational individuation across heterogeneous transformations adds reproducible information beyond identifier, model, memory, behavior, authority and provenance baselines.

## Current benchmark
20 transformation cases span identifier, model, memory, tools, authority, policy, retrieval, runtime, role and provenance. Labels are purpose-conditioned and must be generated independently of the SFI-A scorer.

## Falsifiers
1. Best existing/single-axis baseline equals or exceeds SFI-A on held-out cases.
2. Gains disappear under matched-complexity control.
3. Generalization collapses across purposes/transformation classes.
4. Adjudicator disagreement shows that labels are fundamentally underdetermined beyond purpose-local judgments.

## Required evidence next
- blind adjudication panel;
- executable real-agent instantiations for a subset of transformation cases;
- frozen baseline implementations;
- development/held-out split;
- calibration and abstention analysis;
- uncertainty and disagreement reporting.
