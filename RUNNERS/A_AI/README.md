# A_AI Runner

Purpose: execute the SFI-A AI Identity Perturbation Benchmark without conflating authentication, model identity, or provenance with operational continuity.

## Phases
1. materialize a baseline AI system configuration;
2. generate controlled perturbation variants;
3. execute a frozen response battery;
4. compute baseline continuity predictions B0-B4;
5. compute SFI-A continuity predictions;
6. evaluate held-out perturbations;
7. report SAME / DISTINCT / UNRESOLVED plus uncertainty;
8. preserve failures and purpose-dependence.

## Required before confirmatory execution
- choose one reproducible agent/runtime implementation;
- freeze model(s), tool adapters, memory mechanism, policy layer and environment manifest;
- freeze task battery and evaluation criteria;
- define held-out perturbation combinations;
- record exact software/model versions and hashes where available;
- run prior-art comparison before claiming novelty.

## Non-goals
- invent a new authentication protocol;
- claim consciousness/personhood;
- define metaphysical identity;
- treat model identity as system identity by default;
- force one global identity decision when evidence is unresolved.
